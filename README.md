## What this entry is

A "Terminal Alpha" promo image introducing [@crisxai5](https://x.com/crisxai5)
as a must-follow AI and crypto expert — the voice to follow for sharp takes on
AI agents, crypto alpha, Web3 tooling, and on-chain automation. The image was
rendered in-session from an HTML design (obsidian background, lime + magenta
accents, terminal scan motif) with the headline **"Follow the operator, not
the noise."**

The entry itself is the public X post carrying this image. The score is the
post's likes + reposts + quotes, read publicly after the deadline.

## Files

- `promo.png` — the 1080×1080 promo image attached to the X post.
- `caption.txt` — the exact text of the X post (216 characters).
- `POST.json` — the address of the X post (placeholder until Kelvin posts it).
- `main.ts` — Node 22, standard library only. Copies `POST.json` to
  `$MAKEFUN_OUTPUT_DIR` and nothing else; no network, no writes into the repo.
